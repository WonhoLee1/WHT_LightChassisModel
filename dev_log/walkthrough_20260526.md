# Walkthrough: WHT Topography 최적화 Free-Free 모달 해석 연동 성공 (2026-05-26)

본 문서는 WHT Topography 비드 최적화 루프(`run_topo.py`)에서 구속 조건(SPC) 없이 순수 자유-자유(Free-Free) 상태의 모달 특성을 정합 평가하도록 연동한 최종 구현 및 실동 검증 결과를 요약합니다.

## 1. 구현 배경 및 목적
- 비드 최적화(`run_topo.py`) 과정에서 고유진동수 해석 결과를 도출할 때, 섀시에 적용된 정적 하중 케이스용 경계 구속조건(SPC)이 그대로 모달 솔버에 바인딩되어 강체 모드가 3개 수준으로 축소되어 표현되는 현상이 존재하였습니다.
- 섀시 본연의 고유 진동성 및 순수 Bending/Torsion 특성을 평가하기 위해 **구속 조건이 배제된 완전 Free 상태의 값을 기준으로 고유진동수를 추출**하도록 코드를 수정 및 확인하였습니다.

## 2. 핵심 기술 구현
- `wht_topo/solver.py` 내의 `solve` 루프 중 `solve_modal`이 수행되는 시점에 섀시 모델의 `spc_conditions` 리스트를 일시적으로 백업한 후 비워줍니다 (`fea_solver.model.spc_conditions = []`).
- 모달 고유값 해석이 완결된 직후, 기존의 SPC 조건을 다시 안전하게 원상 복구해 줍니다.
- 이를 통해 **정적 하중 케이스의 변위/컴플라이언스 민감도 연산에는 아무런 악영향이나 부작용을 주지 않으면서도, 모달 진동수와 모드 형상 벡터만큼은 완전한 미구속 자유-자유(Free-Free) 상태에서 정상적으로 계산**되도록 처리하였습니다.

## 3. 실동 검증 결과 (`run_topo.py --iters 1`)
- **강체 모드 6개 정수 수렴**: WHT Solver의 모달 출력을 분석한 결과 1번부터 6번 모드 주파수가 `0.0000 ~ 0.0006 Hz`로 수렴하여 **완전한 6개의 자유-자유 강체 모드가 올바르게 표출**됨을 정상 검증 완료했습니다.
- **탄성 주파수 오차 정밀도 확인**: 구속이 풀림과 동시에 7번 탄성 모드 주파수가 **`49.20 Hz`**로 오차 없이 정상 검출되어 섀시의 구조적 진동 특성을 대변합니다.
- **최적화 안정성**: 정적 최적화 하중 케이스(`bending`, `torsion`, `lifting`) 해석 또한 SPC 조건을 성공적으로 읽어 병렬 수행되어 정상 수렴되었습니다.
