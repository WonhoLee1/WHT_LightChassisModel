### 현재 분석 상황 및 제안 (Current Analysis & Proposals)

1. **RBE2 구현 전략 (Stiff Beam vs. Matrix MPC)**:
    - 현재 **JaxSSO** 솔버에는 직접적인 MPC(Multi-Point Constraint) 또는 RBE2 기능이 없습니다.
    - **제안**: 매우 강한 강성을 가진 보 요소(Stiff Beam/Spoke model)를 사용하여 Slave 노드들을 Master 노드에 연결하는 방식을 제안합니다. 이는 솔버 수정 없이 즉시 적용 가능하지만, 강성이 너무 높을 경우 수치적 불안정성이 생길 수 있습니다. 이 방식이 괜찮으실까요, 아니면 솔버 레벨에서 직접 행렬을 제어하는 방식을 원하시나요?

2. **Reader 상세 구현 범위**:
    - LS-DYNA의 `*SET_NODE_GENERAL`이나 Abaqus의 `*NSET` 등은 수만 가지 조합(Box, Part, Attribute 등)이 가능합니다.
    - **제안**: 우선적으로 가장 빈번하게 사용되는 **ID 리스트 기반**(`*SET_NODE_LIST`, `*NSET, NSET=NAME, (ID list)`)부터 완벽하게 지원하고, General 구문은 점진적으로 확장하는 방식을 제안합니다. 혹시 즉시 지원이 필요한 특정 옵션이 있으신가요?

3. **반력(Reaction Force) API**:
    - JaxSSO의 `solve()`는 현재 변위(u)를 반환합니다. 반력은 해석 후 $R = K u - F_{ext}$ 수식으로 계산하여 제공해야 합니다.
    - 이를 시각화 필드(`point_data['Reaction_Force']`)에 자동으로 포함하여 ParaView 등에서 바로 볼 수 있게 설계할까요?

4. **객체 지향 데이터 모델 (WHTMeshModel)**:
    - 단순 배열 기반의 IR인 `WHTResultData` 외에, 전처리를 위한 **`WHTMeshModel`** 클래스를 새로 설계할 예정입니다. 이 클래스는 노드, 요소, SET 정보, RBE2 연결 정보를 객체로 관리하여 사용자가 `model.get_nodes_by_set(id)`와 같이 쉽게 접근할 수 있도록 하겠습니다.

### 주요 설계 내용 (Key Design)

1. **RBE2 (구속 조건) 구현**:
    - **방법**: JaxSSO의 고유 기능을 유지하기 위해 **Stiff Beam (Spoke) 모델**을 사용합니다. 마스터 노드와 슬레이브 노드들을 매우 강한 보 요소로 연결하여 리지드 바디 거동을 모사합니다.
    - **장점**: 마스터 노드에 직접 하중이나 경계 조건을 부여할 수 있으며, 최적화 시 그래디언트 계산의 안정성을 확보할 수 있습니다.

2. **데이터 모델 (`WHTMeshModel`)**:
    - 단순한 결과 데이터(IR)를 넘어, **SET(노드/요소 그룹), RBE2, 하중 및 경계 조건**을 명시적으로 관리하는 새로운 클래스를 설계합니다.
    - 이를 통해 `model.get_nodes_by_set(id)`와 같이 코드 상에서 직관적으로 모델 정보에 접근할 수 있게 됩니다.

3. **반력(Reaction Force) API**:
    - 사용자께서 필요로 하신 대로, 해석 후 $R = K u - F_{ext}$ 수식을 통해 **각 노드별 반력을 계산하여 제공**합니다. 이는 최적화의 목적 함수나 제약 조건으로 즉시 활용 가능합니다.

4. **IO 확장 (LS-DYNA 등)**:
    - `*SET_NODE_LIST`뿐만 아니라 요청하신 `*SET_NODE_GENERAL`의 **BOX** 및 **PART** 옵션까지 파싱할 수 있도록 리더를 구현합니다.

### 기술적 상세 설계 (Technical Design)

1. **요소별 두께 및 토포그래피 (Design Variables)**:
    - **요소별 두께(Sizing)**: `Model.add_quad`는 인스턴스마다 독립적인 `t` 값을 가질 수 있어, 요소별 두께 최적화가 완벽하게 가능합니다.
    - **토포그래피**: `update_node` 기능을 통해 노드별 Z-offset을 조정하여 국부적인 강성 강화를 유도할 수 있습니다.
    - **통합 관리**: `WHTMeshModel`에서 이 두 인자를 JAX의 자동 미분 변수로 맵핑하여 병렬 최적화를 수행합니다.

2. **Nodal Mapping (Kriging/RBF Interpolation)**:
    - **목표**: 고해상도 메쉬의 해석 결과(변위, 모드 형상 벡터)를 저해상도 최적화 모델의 노드 위치로 샘플링하여 1:1 비교가 가능하게 합니다.
    - **구현**: `scipy.interpolate`의 RBF 커널을 사용하여 타겟 데이터를 필드화한 뒤, 최적화 그리드에 매핑하는 전처리 단계를 구축합니다.

3. **최적화 목적 함수 (Multi-Objective Function)**:
    - $f_{obj} = w_1 \Delta f + w_2 (1-MAC) + w_3 RMSE(disp)$
    - 고유진동수 차이($\Delta f$), 모드 형상 유사도($MAC$), 그리고 3점/4점 벤딩 등의 정적 강성 차이를 통합한 손실 함수를 JAX로 구성합니다.

### 제안하는 핵심 설계 (Key Design Propositions)

1. **물리적 MAC 계산 (Mass-weighted MAC)**:
    - 단순한 벡터 내적은 메쉬 해상도가 다를 경우 오차가 클 수 있습니다.
    - **제안**: 고해상도 타겟 데이터를 저해상도 모델로 매핑한 후, **저해상도 모델의 질량 행렬($M_{low}$)**을 가중치(Weighting matrix)로 사용하여 유사도를 측정합니다. 이는 물리적으로 두 모델의 에너지 분포가 얼마나 유사한지를 보여주는 가장 신뢰도 높은 방식입니다.

2. **JAX & Optax 통합**:
    - **JaxSSO**는 토포그래피 최적화에 필요한 민감도(Sensitivities) 계산의 토대를 제공합니다.
    - 이에 JAX 생태계의 전문 최적화 라이브러리인 **`optax` (Adam 알고리즘 등)**를 직접 연동하여, 수만 개의 설계 변수(노드별 높이, 요소별 두께)를 효율적으로 최적화하도록 구성하겠습니다.

3. **데이터 매핑 (WHTMapper)**:
    - 원형(High-fi)과 단순화 모델(Low-fi) 간의 노드 비일치 문제를 해결하기 위해 **RBF(Radial Basis Function) 보간법**을 모듈화하여 구현합니다. 향후 타겟 구조가 일부 변경되더라도 유연하게 대응할 수 있습니다.

### 트레이 구조에 대한 bead 생성 모델

트레이 3d, 2d 자동 생성 기능에 대해서 몇가지 추가 기능을 구현하고자 한다.
이 트레이 구조는 사실 내가 실제 형상을 준비해서 들고 오기 전에 본 기능 구현을 위해 사용을 하기 위한 목적도 있고, 최적화 형상을 만들기 위한 기본 형상을 코드로 준비하는 것에도 목적인 잇어.

트레이 구조의 현재 생성된 형태애서 시트 메탈 포밍에서의 여러 비드 구조가 존재하는 형태로 만들어야 할 필요가 있어. 그래서 평판 부분에 랜덤하지만 좌우 대칭인 구조로 비드를 생성시키도록 하고 싶어.  비드의 형상은 사각형을 기본으로 최소 길이 10 mm 최대 길이 400 mm로 하고 최대의 깊이는 제한을 둘 것이야. 좌우. 대칭으로 생성되어야 하고, 영역이 중복되는 경우는 최대 높이만 맞춰주면 중복 형상이 가능해. 즉, 사각형이 여러개가 겹치는 구조를 허용하는 것이지. 다만, 비드 영역이 비 비드 영역의 지정된 %를 넘지 않을 때 까지 생성시킬거야.

비드를 캐드 형상으로 만들지, 아니면 메쉬가 된 평판에서 해당 영역의 노드의 좌표를 이동시킬지가 고민이야. 너가 형상을 만들어 내고 hexa 또는 quad 메쉬를 잘 생성 시킬 수 있다면 문제가 없을 것 같아. 그렇지 않으면 만들어진 node에서 면외 방향으로 이동하는 방법을 취해야 할 것 같아.

이 기능을 구현해서 check_hexa_mesh_autobead.py에 3D로 테스트를 먼저해보고, check_shell_mesh_autobead.py에서는 shell로 테스트해보자.

가장 핵심적인 접근 방식은 다음과 같습니다.

1. **메쉬 모핑(Warping)**: 사용자의 선호에 따라, 바닥 판의 노드 리스트를 탐색해 수직(Z축)으로 좌표를 올려 비드를 형성합니다. (Hexa 솔리드 모델일 경우 $Z \le 0$인 모든 레이어를 동일한 양만큼 이동시켜 **두께를 완벽히 유지**합니다.)
2. **랜덤 대칭 비드 규칙**: 중복(Overlap)을 허용하며 겹치는 구간은 Max Depth로 유지합니다. 커버리지 % 수치에 도달할 때까지 난수로 사각형을 찍습니다.
3. **가우시안 필터링 도입 (질문)**: 단순히 사각형 영역만 뚝 잘라 올리면 요소가 수직으로 찢어져(Negative Jacobian 등) 유한요소해석이 불가능할 수 있습니다. 그래서 **비드 맵(Height Map)에 2D 스무딩 렌즈(블러 필터)를 적용**하여 실제 철판 프레스 모양처럼 경사면이 부드럽게 넘어가도록 설계했
