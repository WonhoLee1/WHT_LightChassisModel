# Control Center (Monitor UI) 개선 및 버그 수정 결과

`monitor_ui.py`를 수정하여 사용자 편의성을 높이고 보고된 버그들을 해결하였습니다.

## 주요 변경 사항

### 1. "항상 위 (Stay on Top)" 기능 구현
- **상단 컨트롤바 버튼**: "Stay on Top: OFF/ON" 버튼을 통해 창의 최상단 유지 여부를 토글할 수 있습니다.
- **단축키 (Ctrl+T)**: 키보드만으로도 빠르게 해당 기능을 켜고 끌 수 있습니다.
- **용도**: MuJoCo 시뮬레이션 창 등 다른 큰 창들에 모니터가 가려지는 문제를 방지합니다.

### 2. 리셋(Reset) 대응 및 데이터 초기화
- **자동 감지**: 해석이 다시 시작되어 `iter=0` 데이터가 들어오면 기존 히스토리를 자동으로 감지하여 초기화합니다.
- **수동 리셋**: "Reset UI" 버튼을 추가하여 사용자가 원할 때 언제든 그래프와 테이블을 비울 수 있게 하였습니다.
- **안정성**: `_clear_history()` 메서드를 통해 모든 내부 버퍼와 UI 위젯을 안전하게 초기화합니다.

### 3. 그래프 갱신 버그 수정
- **상태 처리**: 시뮬레이션이 중단(`STOP`)된 이후에도 마지막 데이터가 손실되지 않도록 갱신 로직을 개선하였습니다.
- **갱신 보장**: `_update_height_plot` 호출 시 `draw_idle()`을 추가하여 슬라이더 조작 시 그래프가 즉각적으로 반영되도록 하였습니다.

### 4. UI 레이아웃 정교화
- **상단 컨트롤바**: 상태 표시(`status_label`), 중단 요청(`stop_btn`), 리셋(`reset_btn`), 항상 위 토글(`top_btn`)을 한곳에 모아 배치하였습니다.
- **상태 피드백**: Ready, Running, STOP Requested, Completed 등 현재 상태를 색상과 함께 실시간으로 표시합니다.
