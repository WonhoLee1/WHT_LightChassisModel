# Optimization Monitor UI 및 Solver 기능 개선

사용자 요청에 따라 Monitor UI 편의성 개선 및 모달 해석 결과 처리와 관련된 작업을 모두 완료하였습니다.

## 주요 변경 사항 요약

### 1. Summary Table 고정 열 및 사이즈, 데이터 표시 버그 수정
- 좌측에 위치한 고정 테이블의 "Iter 0" 컬럼을 사용자 요청에 따라 제거하고, "No", "항목", "설명" 3개의 컬럼만 남겼습니다. "Iter 0" 컬럼은 우측의 스크롤 테이블로 이동하여 Iter 1과 나란히 표시되도록 수정하였습니다.
- 테이블의 항목 이름과 설명 부분의 헤더 사이즈 모드를 변경(`Interactive` 모드 적용)하여 사용자가 마우스로 자유롭게 폭을 드래그해 조절할 수 있도록 조치하였습니다.
- 이전 작업 중 함수 호출 인터페이스 변경으로 인해 발생했던 버그(`_append_summary_row`의 인자 누락 에러)를 수정하였습니다. 이로 인해 사라졌던 항목들(모달 해석의 주파수 및 응력, 변형 에너지 값들)이 다시 정상적으로 테이블에 복원되어 표시됩니다.

### 2. Iteration 리스트, 콤보 및 슬라이더 연동 로직 정상화 (버그 픽스)
- Iteration 목록(ListWidget 및 ComboBox)에서 `Latest` 항목을 모두 삭제하고, 번호가 "Iter 0", "Iter 1" ... 의 형태로 정방향(순차적)으로 기입되도록 수정하였습니다.
- 리스트, 콤보 박스, 그리고 아래쪽의 슬라이더가 서로 완벽하게 동기화되도록 이벤트 로직을 개선했습니다. 슬라이더를 1~N으로 움직이면 실제 이터레이션 번호와 매칭되어 플롯이 올바르게 갱신됩니다.
- Height Distribution 탭에서 이터레이션 다중 선택과 단일 선택을 오갈 때 서브플롯(Subplot)의 레이아웃이 겹치거나 지워지지 않는 버그를 수정하였습니다. 이제 선택된 갯수가 바뀔 때마다 도화지가 완전히 초기화(Refresh)된 뒤 새 레이아웃으로 플롯이 깔끔하게 그려집니다.

### 3. Iteration Results (Height Distribution) 탭 범례 및 컨트롤 레이아웃 개선
- **Legend 연동 오류 수정**: 2D 도면 플롯 시 다중 선택/단일 선택 모드에 따라 Legend(컬러바)가 하드코딩되어 강제로 숨겨지거나 표시되던 버그를 수정했습니다. 이제 사용자가 "Legend 표시" 체크박스를 클릭하는 즉시 컬러바가 동적으로 렌더링되거나 숨겨집니다. 초기값은 체크된 상태(Checked)로 설정되었습니다.
- **컨트롤 레이아웃 위치 이동**: 왼쪽 리스트 패널 하단에 존재하던 "Legend 표시" 체크박스와 "Subplot 열" 설정(SpinBox)을 우측 캔버스의 상단 컨트롤 막대로 끌어올렸습니다. 슬라이더와 Contour 체크박스의 바로 오른쪽(구분선 추가)에 나란히 배치하여 사용자가 플롯 설정 요소를 한 곳에서 일괄 제어할 수 있도록 편의성을 높였습니다.

### 4. Modal Analysis 테이블 강체 모드 표시 추가
- `Modal Analysis` 테이블의 첫 번째 행에 **`RBody Modes`** 라벨을 추가하였습니다.
- 내부적으로 제거된 강체 모드의 개수(6개)를 표시해달라는 사용자 요청에 따라, 첫 행(`RBody Modes`)에는 값으로 **`6`**을 고정적으로 기입하도록 로직을 반영했습니다.
- 실제 도출된 고유 진동수는 두 번째 행(`Mode 1`)부터 기존과 동일하게 순차적으로 기록됩니다.

### 5. 다중 선택 시 Subplot 정렬 방식 변경 (열 → 행 기준)
- **Convergence Curve** 및 **Iteration Results** 두 탭 모두에서 다중 데이터를 선택했을 때 적용되는 서브플롯(Subplot)의 레이아웃 기준을 열(Columns) 제한에서 **행(Rows) 제한**으로 변경했습니다.
- UI 라벨을 기존 `Subplot 열:` 에서 **`Subplot Rows:`**로 직관적으로 수정했습니다.
- 최대 제한 설정 범위를 기존 4~6 수준에서 최대 **10행**까지 여유롭게 늘려 슬라이더(SpinBox)를 조절할 수 있도록 반영했습니다. 이제 데이터를 많이 선택하더라도 원하는 세로 행 개수에 맞춰 화면이 자동 분할됩니다.

### 6. 코드 전반 재점검 및 잔존 버그 해결
- 코드를 전체적으로 재점검한 결과, 단일 플롯을 렌더링할 때 데이터를 가져오는 `_get_snap` 헬퍼 함수 내부에 이전에 사용하던 "Latest 옵션에 기반한 역방향 인덱스 조회" 로직의 잔재가 남아있음을 발견했습니다. 
- 이를 최근 수정한 정방향 인덱싱(0번부터 순차 매칭) 로직으로 완전히 교체하여, 특정 Iteration 번호를 선택했을 때 데이터가 엉뚱한 번호로 매칭되거나 에러가 발생하는 치명적인 잠재적 버그를 완벽하게 차단했습니다.

### 2. Iteration Results 탭 레이아웃 개편 및 글자색 수정
- 리스트 영역, 캔버스 영역, 하단 컨트롤 및 텍스트 박스가 상/중/하 로 명확하게 분리되도록 레이아웃을 수정하였습니다 (`QVBoxLayout`을 기준 루트로 삼음).
- 좌측에 위치하는 Iteration 목록 리스트의 최소 폭을 `154`로 지정하여 기존 대비 약 1.4배 넓게 보이도록 적용하였습니다.
- 하단 상태 표시 텍스트 창의 글자 색상을 어두운 파란색 계열에서 `#d4d4d4` (기본 텍스트 색상)로 변경하여 가독성을 높였습니다.

## 추가 버그 재점검 및 강체 모드 표시 로직 수정 (2026-06-12)

### 1. `_rebuild_history_ui` 모달 테이블 복원 버그 수정 및 `RBody Modes` 로직 적용
- `update_history` 함수뿐만 아니라, 히스토리가 다시 로드될 때 호출되는 `_rebuild_history_ui` 함수 내에서도 모달 분석 결과 테이블이 일치된 레이아웃으로 로드되도록 로직을 일치시켰습니다.
- 이전에는 `_rebuild_history_ui`에서 테이블 행 수(`setRowCount`)를 늘리기 전에 빈 행에 접근하려 하여 데이터가 누락되던 버그가 있었습니다. 수정을 통해 `Ref. (Hz)` 및 각 `Iter N` 컬럼의 0번 행에 `"6"`이 누락 없이 대입되고 세로 헤더도 `"RBody Modes"`와 `"Mode 1~N"`으로 깔끔하게 매치되도록 수정했습니다.

### 2. 콤보박스 및 리스트의 `"Latest"` 항목 완전 제거 및 1:1 인덱싱화
- 콤보박스와 이터레이션 리스트에서 `"Latest"` 문자열을 완전히 걷어냈습니다.
- 이에 따라 `self.height_slider` 의 값(`0 ~ N-1`)과 콤보박스 및 리스트의 선택 인덱스(`0 ~ N-1`), 그리고 스냅샷 리스트(`self.height_snapshots`)의 인덱스가 완벽히 `1:1`로 매핑됩니다.
- 이전에는 `"Latest"` 항목 선택 시 0번 스냅샷(Iter 0)이 맵에 그려지던 인덱스 밀림 현상 및 다중 선택 모듈의 인덱스 불일치 버그가 근본적으로 해결되었습니다.
- 데이터 실시간 수신 시(`_on_data_received`), 슬라이더가 최신(마지막) 인덱스를 가리키고 있었다면 새로 들어오는 데이터도 자동으로 끝까지 갱신 및 추적하도록 개선하여 편의성을 유지했습니다.
