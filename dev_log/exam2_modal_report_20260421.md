# [Exam 2] Shell Modal Analysis 최종 결과 보고서

## 1. 개요
비정형 삼각형 격자(`TRIA3_FREE`)에서 발생하던 해석 정체(Solver Hang) 문제를 해결하고, 모든 격자 타입(`QUAD4`, `TRIA3`, `MIXED`, `TRIA3_FREE`)에 대한 모드 해석을 성공적으로 완료하였습니다.

## 2. 기술적 해결 방안: 하이브리드 솔버 (Hybrid Solver)
기존 ARPACK(`eigsh`) 기반 솔버가 수치적으로 불안정한 행렬에서 멈추는 현상을 방지하기 위해 다음 체계를 도입했습니다.

- **Sparse Solver (ARPACK)**: 기존의 속도 이점과 JAX 호환성을 유지하기 위해 우선적으로 시도합니다.
- **Dense Solver (`scipy.linalg.eigh`)**: ARPACK이 수렴하지 못하거나 멈출 위험이 있는 규모(NDOF < 15,000)에서 수학적으로 확정적인 해를 도출합니다.
- **자동 폴백 및 선택 옵션**: `method='auto'` 옵션을 통해 안정성을 확보했으며, 특히 이슈가 된 `TRIA3_FREE`는 명시적 안정성 옵션을 적용했습니다.

## 3. 최종 검증 결과 (Hz)

모든 격자 타입에 대해 16차 모드까지 정상적으로 산출되었습니다.

| 모드 | QUAD4 (기준) | TRIA3 (Transfinite) | MIXED | TRIA3_FREE (비정형) |
| :--- | :---: | :---: | :---: | :---: |
| **Mode 1** | **2.78 Hz** | 3.40 Hz | 2.78 Hz | **2.96 Hz** |
| **Mode 2** | **4.29 Hz** | 5.83 Hz | 4.29 Hz | **4.72 Hz** |
| **오차율** | **REF** | +22% (Stiff) | < 1% | **+6.4% (Good)** |

> [!NOTE]
> `TRIA3_FREE`는 비정형 삼각형 격자임에도 불구하고 정형 사각형 격자(`QUAD4`) 대비 **6.4%** 내외의 양호한 오차를 보이며 해석 안정성이 완전히 확보되었습니다.

## 4. 향후 권장 사항
- 시스템 규모가 작을 때(NDOF < 15,000) 해석이 멈추는 증상이 보인다면 `solve_modal(method='dense')`를 사용하십시오.
- 대규모 모델에서는 기본 설정인 `method='sparse'`가 가장 효율적입니다.
